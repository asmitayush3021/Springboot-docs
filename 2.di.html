Dependency Injection & IoC

IoC container, bean lifecycle, scopes, injection types, circular deps — deeply explained

1. What Is IoC and Why It Matters

❌ Without IoC — tight coupling
public class OrderService {
    // You control creation — tightly coupled
    private UserRepository repo =
        new JdbcUserRepository(
            new DataSource("jdbc:...")
        );
    // Hard to test, hard to swap
    // DB connection created on class load
}
✅ With IoC — decoupled
@Service
public class OrderService {
    // Container controls creation
    private final UserRepository repo;

    public OrderService(UserRepository repo) {
        this.repo = repo;
    }
    // Easy to test (inject mock)
    // Swap JdbcRepo → JpaRepo: 0 changes
}

2. The ApplicationContext Explained

ApplicationContext (IoC Container) │ ├── BeanDefinitionRegistry — metadata about all beans (class, scope, deps) ├── BeanFactory — core: getBean(), containsBean() ├── MessageSource — i18n ├── ApplicationEventPublisher — event system └── ResourceLoader — classpath:// file:// https:// AnnotationConfigApplicationContext (Spring Boot's choice) │ reads @Component, @Service, @Repository, @Controller, @Configuration └── BeanDefinition per class → instantiate → wire → register

How Spring Scans and Creates Beans

Startup sequence: 1. ComponentScan → find all @Component classes in packages 2. BeanDefinition created for each (scope, lazy, primary, deps list) 3. BeanFactoryPostProcessor runs → can modify definitions (@PropertySource reads here) 4. BeanPostProcessors registered (AutowiredAnnotationBPP, AopProxyBPP) 5. Singleton beans instantiated eagerly (unless @Lazy) 6. Dependency injection performed (constructor → setter → field) 7. @PostConstruct called 8. InitializingBean.afterPropertiesSet() called 9. Context is ready — app handles requests 10. On shutdown: @PreDestroy → DisposableBean.destroy()

3. Bean Lifecycle In Full Detail

@Component
public class ConnectionPool implements InitializingBean, DisposableBean {

    private HikariDataSource dataSource;

    // Phase 1: Constructor called by Spring
    public ConnectionPool() {
        System.out.println("1. Constructor");
    }

    // Phase 2: Dependencies injected
    @Value("${db.url}")
    private String dbUrl;    // injected after construction

    // Phase 3: BeanPostProcessor.postProcessBeforeInitialization()
    // (Spring AOP proxies created here)

    // Phase 4: @PostConstruct (PREFERRED)
    @PostConstruct
    public void init() {
        System.out.println("3. @PostConstruct — dbUrl available: " + dbUrl);
        dataSource = new HikariDataSource();
        dataSource.setJdbcUrl(dbUrl);
        dataSource.setMaximumPoolSize(20);
    }

    // Phase 5: InitializingBean.afterPropertiesSet() (same timing as @PostConstruct)
    @Override
    public void afterPropertiesSet() {
        System.out.println("4. afterPropertiesSet");
    }

    // Phase 6: BeanPostProcessor.postProcessAfterInitialization()

    // ... bean serves requests ...

    // Phase 7: @PreDestroy (on context shutdown)
    @PreDestroy
    public void cleanup() {
        System.out.println("7. @PreDestroy — closing pool");
        dataSource.close();
    }

    // Phase 8: DisposableBean.destroy()
    @Override
    public void destroy() {
        System.out.println("8. destroy()");
    }
}

// Output order:
// 1. Constructor
// 3. @PostConstruct — dbUrl available: jdbc:postgresql://...
// 4. afterPropertiesSet
// [app runs]
// 7. @PreDestroy — closing pool
// 8. destroy()

4. Singleton vs Prototype Scope

🔵 Singleton (default)
@Service  // = @Scope("singleton")
public class UserService {
    // ONE instance in entire context
    // Shared across ALL threads
    // Created at startup
}

// ctx.getBean(UserService.class) twice
// → returns SAME object both times
// a == b → true
🟠 Prototype
@Component
@Scope("prototype")
public class ReportGenerator {
    // NEW instance every injection
    // @PreDestroy NOT called!
    // You manage lifecycle
}

// ctx.getBean() twice
// → returns DIFFERENT objects
// a == b → false

The Scope Trap — Prototype in Singleton

❌ BROKEN: Singleton holds Prototype — always same instance!
@Service  // singleton
public class OrderService {
    @Autowired
    private ShoppingCart cart; // prototype
    // cart NEVER changes!
    // Spring injects once at startup
    // All users share same cart!
}
✅ Fix: ApplicationContext or Provider
@Service
public class OrderService {
    @Autowired
    private ApplicationContext ctx;

    public ShoppingCart newCart() {
        // fresh prototype each call
        return ctx.getBean(ShoppingCart.class);
    }
    // OR: @Lookup method injection
    @Lookup
    public ShoppingCart getCart() { return null; }
    // Spring overrides this at runtime!
}

5. Constructor vs Field vs Setter Injection

// ✅ RECOMMENDED: Constructor Injection
@Service
public class PaymentService {
    // final fields = immutable after construction
    private final PaymentGateway gateway;
    private final OrderRepository orderRepo;
    private final EmailService emailService;

    // @Autowired not needed (single constructor)
    public PaymentService(PaymentGateway gateway,
                          OrderRepository orderRepo,
                          EmailService emailService) {
        this.gateway     = Objects.requireNonNull(gateway);
        this.orderRepo   = Objects.requireNonNull(orderRepo);
        this.emailService = Objects.requireNonNull(emailService);
    }
}
// Benefits:
// 1. Dependencies explicit — can't miss them
// 2. Fields can be final (thread-safe)
// 3. Easy to test: new PaymentService(mockGW, mockRepo, mockEmail)
// 4. Circular dependency detected EARLY at startup
// 5. No Spring dependency in test code
// ⚠️ Field injection — convenient but problematic
@Service
public class PaymentService {
    @Autowired  // Spring uses reflection to inject
    private PaymentGateway gateway;

    @Autowired
    private OrderRepository orderRepo;
}
// Problems:
// 1. Can't be final (mutable!)
// 2. Hidden dependencies (you don't see them in constructor)
// 3. Testing requires Spring context OR reflection hacks:
//    ReflectionTestUtils.setField(service, "gateway", mockGW);
// 4. NPE outside Spring context (unit test: gateway is null)
// 5. Circular deps detected LATE (at first use, not startup)
// Setter injection — for optional dependencies
@Service
public class NotificationService {
    private SmsProvider smsProvider;  // optional

    // @Autowired(required = false) — ok if bean missing
    @Autowired(required = false)
    public void setSmsProvider(SmsProvider smsProvider) {
        this.smsProvider = smsProvider;
    }

    public void notify(String msg) {
        if (smsProvider != null) smsProvider.send(msg);
    }
}
// Use setter injection when dependency is truly optional

7. Circular Dependencies

❌ Circular Dep — startup crash
@Service
public class A {
    private final B b;
    public A(B b) { this.b = b; }
}

@Service
public class B {
    private final A a;
    public B(A a) { this.a = a; }
}
// BeanCreationException:
// Circular dependency:
// A → B → A
// Spring can't create either!
✅ Refactor: extract shared service
@Service
public class SharedService {
    // extract common logic here
}

@Service
public class A {
    private final SharedService shared;
}

@Service
public class B {
    private final SharedService shared;
}
// A and B no longer depend
// on each other directly!

Emergency Workarounds (use reluctantly)

// Option 1: @Lazy — delays bean creation, breaks cycle
@Service
public class A {
    public A(@Lazy B b) { this.b = b; }  // B is a proxy until first use
}

// Option 2: setter injection (not recommended but works)
@Service
public class A {
    private B b;
    @Autowired
    public void setB(B b) { this.b = b; }  // set after both constructed
}

// Option 3: ApplicationContext lookup (lazy resolution)
@Service
public class A implements ApplicationContextAware {
    private ApplicationContext ctx;
    private B getB() { return ctx.getBean(B.class); }  // resolved on demand
}

// Circular dependency is usually a design smell:
// → Split the class (SRP violation)
// → Extract interface + use events (@EventPublisher)

8. How Spring Resolves Beans Internally

getBean("orderService"): 1. Check singletonObjects cache (3-level cache) └─ Level 1: fully-initialized singletons → return immediately └─ Level 2: early references (partially initialized) → for circular deps └─ Level 3: singletonFactories → ObjectFactory for early expose 2. Not in cache → createBean() ├── instantiateBean() → constructor called → Object in L3 cache ├── populateBean() → @Autowired fields resolved (recursive getBean) └── initializeBean() → BPP.postProcess + @PostConstruct + afterPropertiesSet 3. Move from L3 → L1 (fully initialized) Circular dependency (A needs B, B needs A): Create A shell → put in L3 → inject B → B needs A → getBean(A) finds A in L2 early-reference cache ✓ → B complete → inject into A → A complete → move to L1
💡 Spring Internals Insight
The three-level singleton cache is how Spring solves some circular dependencies automatically (field/setter injection). Constructor injection disables the early reference mechanism — which is why it forces you to fix design instead of silently papering over it.

            @RequestParam(required = false) OrderStatus status,
            @RequestParam(required = false) String customerId,
            @PageableDefault(size = 20, sort = "createdAt",
                             direction = Sort.Direction.DESC) Pageable pageable) {
        return ResponseEntity.ok(orderService.findOrders(status, customerId, pageable));
    }

    // GET /api/v1/orders/42
    @GetMapping("/{id}")
    public ResponseEntity<OrderDetailDto> getOrder(@PathVariable long id) {
        return orderService.findById(id)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
    }

    // POST /api/v1/orders
    @PostMapping
    public ResponseEntity<OrderDetailDto> createOrder(
            @Valid @RequestBody CreateOrderRequest request,
            UriComponentsBuilder ucb,
            @RequestHeader(value = "Idempotency-Key", required = false) String idempotencyKey) {

        OrderDetailDto order = orderService.createOrder(request, idempotencyKey);

        URI location = ucb.path("/api/v1/orders/{id}")
            .buildAndExpand(order.getId()).toUri();

        return ResponseEntity.created(location).body(order);  // 201 Created
    }

    // PATCH /api/v1/orders/42
    @PatchMapping("/{id}")
    public ResponseEntity<OrderDetailDto> patchOrder(
            @PathVariable long id,
            @Valid @RequestBody PatchOrderRequest request) {
        return ResponseEntity.ok(orderService.patchOrder(id, request));
    }

    // DELETE /api/v1/orders/42
    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)  // 204
    public void deleteOrder(@PathVariable long id) {
        orderService.deleteOrder(id);
    }
}

4. Global Error Handling

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public ErrorResponse handleValidation(MethodArgumentNotValidException ex) {
        Map<String, String> errors = new LinkedHashMap<>();
        ex.getBindingResult().getFieldErrors().forEach(e ->
            errors.put(e.getField(), e.getDefaultMessage()));

        return ErrorResponse.builder()
            .status(400)
            .error("Validation Failed")
            .details(errors)
            .timestamp(Instant.now())
            .build();
    }

    @ExceptionHandler(EntityNotFoundException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public ErrorResponse handleNotFound(EntityNotFoundException ex) {
        return ErrorResponse.of(404, ex.getMessage());
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public ErrorResponse handleGeneral(Exception ex) {
        log.error("Unhandled exception", ex);
        // NEVER expose stack trace to client!
        return ErrorResponse.of(500, "Internal server error");
    }
}

        return orderRepo.findAll(spec, pageable)

6. Idempotency

// Client sends Idempotency-Key header with POST
// Duplicate requests with same key return cached response
@Service
public class IdempotencyService {

    private final RedisTemplate<String, IdempotencyRecord> redis;

    public <T> T executeIdempotently(
            String key,
            Class<T> responseType,
            Supplier<T> operation) {

        String cacheKey = "idempotency:" + key;

        // Check if this key was already processed
        IdempotencyRecord existing = redis.opsForValue().get(cacheKey);
        if (existing != null) {
            log.info("Idempotent replay for key: {}", key);
            return responseType.cast(existing.getResponse());
        }

        // Execute the operation
        T result = operation.get();

        // Cache result for 24 hours
        redis.opsForValue().set(
            cacheKey,
            new IdempotencyRecord(result),
            Duration.ofHours(24)
        );

        return result;
    }
}

// Usage in controller:
@PostMapping
public ResponseEntity<OrderDetailDto> createOrder(
        @Valid @RequestBody CreateOrderRequest req,
        @RequestHeader("Idempotency-Key") String idempotencyKey) {

    OrderDetailDto order = idempotencyService.executeIdempotently(
        idempotencyKey,
        OrderDetailDto.class,
        () -> orderService.createOrder(req)
    );
    return ResponseEntity.ok(order);
}

2. Complete JWT Implementation

// dependency: io.jsonwebtoken:jjwt-api:0.12.3 + jjwt-impl + jjwt-jackson
@Service
public class JwtService {

    @Value("${jwt.secret}")  // 256-bit base64 key in application.properties
    private String secretKey;

    @Value("${jwt.access-token-expiry-ms:900000}")  // 15 minutes
    private long accessExpiry;

    private SecretKey getSigningKey() {
        byte[] keyBytes = Decoders.BASE64.decode(secretKey);
        return Keys.hmacShaKeyFor(keyBytes);  // HMAC-SHA256
    }

    public String generateAccessToken(UserDetails user) {
        Map<String, Object> claims = new HashMap<>();
        // Add roles to token
        claims.put("roles", user.getAuthorities().stream()
            .map(GrantedAuthority::getAuthority).toList());

        return Jwts.builder()
            .subject(user.getUsername())
            .claims(claims)
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + accessExpiry))
            .signWith(getSigningKey())  // HS256
            .compact();
    }

    public String extractUsername(String token) {
        return extractClaim(token, Claims::getSubject);
    }

    public boolean isTokenValid(String token, UserDetails userDetails) {
        final String username = extractUsername(token);
        return username.equals(userDetails.getUsername()) && !isTokenExpired(token);
    }

    private boolean isTokenExpired(String token) {
        return extractClaim(token, Claims::getExpiration).before(new Date());
    }

    private <T> T extractClaim(String token, Function<Claims, T> claimsResolver) {
        final Claims claims = Jwts.parser()
            .verifyWith(getSigningKey())
            .build()
            .parseSignedClaims(token)   // throws if invalid/expired
            .getPayload();
        return claimsResolver.apply(claims);
    }
}
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtService jwtService;
    private final UserDetailsService userDetailsService;

    @Override
    protected void doFilterInternal(
            HttpServletRequest request,
            HttpServletResponse response,
            FilterChain filterChain) throws ServletException, IOException {

        // 1. Extract Bearer token
        final String authHeader = request.getHeader("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            filterChain.doFilter(request, response);  // no token, pass through
            return;
        }

        final String jwt = authHeader.substring(7);  // strip "Bearer "

        try {
            // 2. Extract username from JWT
            final String username = jwtService.extractUsername(jwt);

            // 3. Only authenticate if not already authenticated
            if (username != null &&
                SecurityContextHolder.getContext().getAuthentication() == null) {

                // 4. Load user from DB (checks if user still active)
                UserDetails userDetails = userDetailsService.loadUserByUsername(username);

                // 5. Validate token (signature + expiry + username match)
                if (jwtService.isTokenValid(jwt, userDetails)) {

                    // 6. Create authentication and set in context
                    UsernamePasswordAuthenticationToken auth =
                        new UsernamePasswordAuthenticationToken(
                            userDetails,
                            null,
                            userDetails.getAuthorities()  // roles
                        );
                    auth.setDetails(new WebAuthenticationDetailsSource()
                        .buildDetails(request));

                    SecurityContextHolder.getContext().setAuthentication(auth);
                    // downstream controllers can now call SecurityContextHolder.getContext()
                }
            }
        } catch (JwtException e) {
            // Invalid/expired token — just don't authenticate
            log.warn("JWT validation failed: {}", e.getMessage());
        }

        filterChain.doFilter(request, response);
    }

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String path = request.getRequestURI();
        return path.startsWith("/api/auth/");  // skip for login/register
    }
}
@Configuration
@EnableWebSecurity
@EnableMethodSecurity   // enables @PreAuthorize on methods
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtFilter;
    private final UserDetailsService userDetailsService;

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        return http
            // Stateless: no sessions
            .sessionManagement(s -> s.sessionCreationPolicy(STATELESS))
            // CSRF disabled for REST APIs (stateless = no cookies)
            .csrf(AbstractHttpConfigurer::disable)
            // CORS config
            .cors(cors -> cors.configurationSource(corsConfigSource()))
            // Authorization rules
            .authorizeHttpRequests(auth -> auth

                .requestMatchers("/api/admin/**").hasRole("ADMIN")

            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class)
            // Custom 401/403 handlers
            .exceptionHandling(ex -> ex

                    res.setStatus(401);
                    res.setContentType("application/json");
                    res.getWriter().write("""
                        {"error":"Unauthorized","message":"Token required"}""");
                })
                .accessDeniedHandler((req, res, e) -> {
                    res.setStatus(403);

    private final JwtService jwtService;

    private final RefreshTokenService refreshTokenService;

    public ResponseEntity<AuthResponse> login(
            @Valid @RequestBody LoginRequest request) {

            // Throws if credentials wrong
            authManager.authenticate(
                new UsernamePasswordAuthenticationToken(
                    request.getEmail(), request.getPassword())
            );
        } catch (AuthenticationException e) {
            throw new ResponseStatusException(HttpStatus.UNAUTHORIZED, "Invalid credentials");
        }

        UserDetails user = userDetailsService.loadUserByUsername(request.getEmail());
        String accessToken = jwtService.generateAccessToken(user);
        String refreshToken = refreshTokenService.create(user.getUsername());

        return ResponseEntity.ok(AuthResponse.builder()
            .accessToken(accessToken)
            .refreshToken(refreshToken)
            .expiresIn(900)   // 15 minutes in seconds
            .build());
    }

    public ResponseEntity<UserDto> register(@Valid @RequestBody RegisterRequest req) {
        return ResponseEntity.status(201).body(userService.register(req));

@Service
@RequiredArgsConstructor
public class RefreshTokenService {

    private final RefreshTokenRepository tokenRepo;

    public String create(String username) {
        // Invalidate all existing refresh tokens for user (rotation)
        tokenRepo.deleteByUsername(username);

        String token = UUID.randomUUID().toString();
        RefreshToken entity = RefreshToken.builder()
            .token(token)
            .username(username)
            .expiresAt(Instant.now().plus(7, ChronoUnit.DAYS))
            .build();

        tokenRepo.save(entity);
        return token;
    }

    public AuthResponse refresh(String refreshToken) {
        RefreshToken entity = tokenRepo.findByToken(refreshToken)
            .orElseThrow(() -> new ResponseStatusException(
                HttpStatus.UNAUTHORIZED, "Invalid refresh token"));

        if (entity.getExpiresAt().isBefore(Instant.now())) {
            tokenRepo.delete(entity);
            throw new ResponseStatusException(
                HttpStatus.UNAUTHORIZED, "Refresh token expired");
        }

        UserDetails user = userDetailsService.loadUserByUsername(entity.getUsername());

        // Token rotation: issue new refresh token on each use
        String newAccessToken = jwtService.generateAccessToken(user);
        String newRefreshToken = create(user.getUsername());  // revokes old!

        return AuthResponse.builder()
            .accessToken(newAccessToken)
            .refreshToken(newRefreshToken)
            .expiresIn(900).build();
    }
}

2. Proxy Mechanics — How AOP Works

Two proxy strategies: 1. JDK Dynamic Proxy (when bean implements interface) Bean implements → Proxy implements same interface Proxy.method() → InvocationHandler.invoke() → interceptors → real bean 2. CGLIB Proxy (when bean is concrete class, no interface) Spring subclasses your class at runtime (bytecode generation) Proxy extends YourClass Proxy.method() → MethodInterceptor.intercept() → interceptors → super.method() Spring Boot default: CGLIB for @Configuration, JDK for interfaces Spring AOP 6: prefer interface → JDK proxy for better performance Self-invocation limitation: this.anotherMethod() ← calls on REAL object, bypasses proxy! → @Transactional inside same class won't work → Fix: inject self OR use ApplicationContext.getBean()

3. Advice Types with Examples

@Aspect
@Component
public class ServiceAuditAspect {

    // Pointcut: all methods in @Service classes
    @Pointcut("within(@org.springframework.stereotype.Service *)")
    public void serviceLayer() {}

    // Pointcut: all public methods
    @Pointcut("execution(public * *(..))")
    public void publicMethods() {}

    // @Before: runs before method, can't stop execution (except throw)
    @Before("serviceLayer() && publicMethods()")
    public void logEntry(JoinPoint jp) {
        log.debug("→ {}.{}({})",
            jp.getTarget().getClass().getSimpleName(),
            jp.getSignature().getName(),
            Arrays.toString(jp.getArgs())
        );
    }

    // @AfterReturning: runs only on SUCCESS, can see return value
    @AfterReturning(pointcut = "serviceLayer()", returning = "result")
    public void logSuccess(JoinPoint jp, Object result) {
        log.debug("← {} returned: {}", jp.getSignature().getName(), result);
    }

    // @AfterThrowing: runs only on EXCEPTION, can see it
    @AfterThrowing(pointcut = "serviceLayer()", throwing = "ex")
    public void logError(JoinPoint jp, Throwable ex) {
        log.error("✗ {} threw: {}", jp.getSignature().getName(), ex.getMessage());
    }

    // @After: always runs (like finally)
    @After("serviceLayer()")
    public void auditTrail(JoinPoint jp) {
        auditService.record(jp.getSignature().toShortString(), Instant.now());
    }

    // @Around: full control, MOST powerful
    @Around("serviceLayer() && publicMethods()")
    public Object measureTime(ProceedingJoinPoint pjp) throws Throwable {
        long start = System.currentTimeMillis();
        try {
            Object result = pjp.proceed();   // actually call the method
            long elapsed = System.currentTimeMillis() - start;
            log.info("⏱ {} took {}ms", pjp.getSignature().toShortString(), elapsed);
            // push to Micrometer metrics
            meterRegistry.timer("service.method",
                "class", pjp.getTarget().getClass().getSimpleName(),
                "method", pjp.getSignature().getName()
            ).record(elapsed, TimeUnit.MILLISECONDS);
            return result;
        } catch (Throwable t) {
            log.error("Method failed after {}ms", System.currentTimeMillis()-start);
            throw t;  // must rethrow!
        }
    }
}

5. Custom Annotation-Based AOP

// Step 1: Define the annotation
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RateLimit {
    int requests() default 100;
    int windowSeconds() default 60;
    String keyExpression() default "user";  // SpEL
}

// Step 2: Create the Aspect
@Aspect
@Component
public class RateLimitAspect {

    private final RateLimiter rateLimiter;

    @Around("@annotation(rateLimit)")  // binds annotation to param
    public Object enforceRateLimit(ProceedingJoinPoint pjp, RateLimit rateLimit)
            throws Throwable {

        // Resolve key from SpEL expression
        String key = resolveKey(rateLimit.keyExpression(), pjp);

        if (!rateLimiter.tryAcquire(key, rateLimit.requests(), rateLimit.windowSeconds())) {
            throw new ResponseStatusException(
                HttpStatus.TOO_MANY_REQUESTS,
                "Rate limit exceeded: " + rateLimit.requests() + " req/" + rateLimit.windowSeconds() + "s");
        }
        return pjp.proceed();
    }

    private String resolveKey(String expression, ProceedingJoinPoint pjp) {
        if ("user".equals(expression)) {
            return SecurityContextHolder.getContext()
                .getAuthentication().getName();
        }
        // Use SpEL parser for complex expressions like "#req.userId"
        return expression;
    }
}

// Step 3: Use it!
@RestController
public class SearchController {

    @GetMapping("/search")
    @RateLimit(requests = 10, windowSeconds = 60, keyExpression = "user")
    public List<Result> search(@RequestParam String q) {
        return searchService.search(q);  // 10 searches/minute/user
    }
}

6. Distributed Tracing Aspect (OpenTelemetry)

@Aspect
@Component
public class TracingAspect {

    private final Tracer tracer;  // OpenTelemetry or Micrometer Brave

    @Around("@annotation(traced)")
    public Object trace(ProceedingJoinPoint pjp, Traced traced) throws Throwable {
        String spanName = traced.value().isEmpty()
            ? pjp.getSignature().toShortString()
            : traced.value();

        Span span = tracer.nextSpan().name(spanName).start();

        try (Tracer.SpanInScope ws = tracer.withSpan(span)) {
            // Add method args as span tags
            MethodSignature sig = (MethodSignature) pjp.getSignature();
            String[] params = sig.getParameterNames();
            Object[] args = pjp.getArgs();
            for (int i = 0; i < params.length; i++) {
                if (isTaggable(args[i])) {
                    span.tag(params[i], String.valueOf(args[i]));
                }
            }

            Object result = pjp.proceed();
            span.tag("outcome", "success");
            return result;

        } catch (Throwable t) {
            span.tag("outcome", "error");
            span.tag("error.message", t.getMessage());
            throw t;
        } finally {
            span.end();
        }
    }
}

7. How @Transactional Works (AOP Under the Hood)

@Transactional method call flow: 1. Caller calls proxy.createOrder(req) 2. TransactionInterceptor (Around advice) fires: a. TransactionManager.getTransaction() — get or create TX b. TX bound to current thread via ThreadLocal c. pjp.proceed() — actual method d. (if no exception): commit() e. (if RuntimeException): rollback() f. (if CheckedException): commit by DEFAULT (unless rollbackFor set) g. TX removed from ThreadLocal Propagation behaviors: REQUIRED (default) — join existing TX or create new REQUIRES_NEW — always new TX, suspend existing NESTED — savepoint within existing TX SUPPORTS — join if exists, otherwise no TX NOT_SUPPORTED — suspend TX, run without NEVER — throw if TX exists MANDATORY — throw if NO TX exists 
// Common @Transactional mistakes:

// ❌ 1. CheckedException doesn't rollback by default
@Transactional
public void transfer() throws InsufficientFundsException {
    debit(); throw new InsufficientFundsException();
    // COMMITS! CheckedException = no rollback
}
// ✅ Fix:
@Transactional(rollbackFor = InsufficientFundsException.class)

// ❌ 2. Self-invocation bypasses proxy
@Service
public class OrderService {
    @Transactional
    public void createOrder() { saveOrder(); }  // ✅ proxy intercepted

    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void saveOrder() { /**/ }
    // ❌ called via this.saveOrder() — new TX NOT created!
}

// ❌ 3. @Transactional on private method — ignored!
@Transactional  // has NO effect on private methods
private void internalSave() { /**/ }
💡 Aspect Ordering
Multiple aspects on same method execute in order. Control with @Order(1) on the aspect class. Lower number = higher priority = outermost wrapper. Spring's own aspects: Security=100, Transaction=200, Caching=300. Your aspects default to lowest priority (last). Add @Order(50) to run before transaction begins.
⚠️ AOP Limitations in Spring
Only public methods — Spring AOP proxies can only intercept public method calls from outside the bean.
Same-class calls bypass proxy — this.annotatedMethod() calls the real object, not the proxy.
Final methods can't be proxied by CGLIB — don't make Spring beans or their methods final.
